실서비스로 바꾸려면

  1. Supabase 새 프로젝트에서 beta_schema.sql 실행
  2. index.html 맨 위 CONFIG에 주소와 publishable 키 입력
  3. Cloudflare Pages에 index.html과 _redirects 올리기
const CONFIG = {
  supabaseUrl: 'https://<ref>.supabase.co',
  supabaseKey: 'sb_publishable_…',
  …
};
